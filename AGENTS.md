# SpeedWatch development

Follow the [Yapr agent policy](https://github.com/yapr/handbook/blob/main/engineering/agent-policy.md) and [PR rules](https://github.com/yapr/handbook/blob/main/engineering/pull-request.md).

- Work on a dedicated branch. Submit a normal PR with test evidence and `作業元: dot（AI支援）`.
- Never publish private portfolio records, raw PageSpeed responses, secrets or unapproved screenshots.
- Missing measurements are not zero. Demo data must be explicitly labeled and never used as production evidence.
- Run `npm test`, `npm run check`, `npm run demo` for relevant changes.
- No merge, production deployment or enabling scheduled production monitoring without explicit approval.
